# ![Rickert Logo](frontend/favicon.ico) Rickert Comic Book Viewer
Rickert is a web-based comic book viewer that features a panel by panel mode. It has been built from the ground up to be functional on small screen devices, such as mobiles.

## Status
At the moment, Rickert is entirely made of frontend JavaScript. It's capable of loading raw images and ZIP/CBZ files, although there's some manual setup required. A proper GUI will be included in a later release.

An optional backend is planned, allowing for transcoding and other additional features.
